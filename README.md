# Abhay & Satarupa — Wedding Reception

A single-page, photo-free wedding reception invitation for 13 December 2026 at 7:00 PM IST, Jalsa Marriage Garden, Dhanbad.

Includes animated clouds, calendar options for Google/Apple/Outlook, driving directions, guest contact, and an original piano-like melody. Music attempts autoplay and starts on the first interaction if required by browser policy. Reduced motion is respected.

## Preview

No build step or dependencies required. Serve the repository root:

```sh
python3 -m http.server 4173
```

Open http://localhost:4173. Deploy the root directory to any static host when ready.

No reception end time was supplied, so the downloadable calendar event specifies only the start time. Guests can adjust duration while saving.
